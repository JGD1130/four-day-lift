# 4-Day Lift — Version 4

A mobile-first four-workout rotation with alternating A1/A2, B1/B2, C1/C2 and D1/D2 sessions.

## V4 highlights
- A → B → C → D rotation independent of weekday.
- Each workout automatically alternates between Variant 1 and Variant 2.
- Two working sets by default on resistance exercises, with an optional third set button.
- Completed exercises automatically collapse and gray out; tap to reopen.
- Last performance is shown by set (weight and reps) when available.
- Text-only FORM guides retain setup, joint-position, movement and common-error cues.
- Programming emphasizes chest/back thickness and includes high-to-low cable fly work for lower-chest emphasis.
- Workout C uses single-leg kickback machine instead of band knee extensions.
- Smith day ends its resistance work with Smith machine bent-over rows.
- Notes, timers, skip, custom exercise, history and Strider finishers remain.

Existing local history/settings use the same storage keys and are migrated into Variant 1 where applicable.
